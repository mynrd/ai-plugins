# mynrd-dispatch

In Codex, first read [the runtime adapter](../../adapters/codex.md), then follow [the shared dispatch workflow](../../commands/mynrd-dispatch.md) with those translations. In Claude Code or Cursor, follow the shared command natively.

Read [the progress schema](../../PROGRESS-SCHEMA.md) before updating state. Require the existing plan and progress file. Use the adapter's specialist selection, actual available delegation tools, or honest sequential fallback. Preserve AC evidence checks, per-task local commits, protected-branch rules, service cleanup, and BUILD/REVISED reports. Never push or mark human verification complete.
